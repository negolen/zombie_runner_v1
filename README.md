# 🧟 Zombie Runner 3D

Three.js & WebGL tabanlı, responsive dikey (9:16) **Hypercasual Runner & Shooter** oyunu.

## 🎮 Temel Özellikler
* **Synthwave Görsel Deneyim:** Dinamik mor-lacivert atmosfer, neon pist bordürleri ve akıcı Three.js animasyonları.
* **Can Sistemi:** 3 kalp başlangıç, maksimum 6 kalp sınırı.
* **No-Skip Kapılar:** Atlanamayan, seviyeye göre artan (min. 7) çarpan kapıları.
* **10 Temalı Boss:** Eklemli yürüyüş, kaçınılamaz şok dalgası ve **x2.5 Kritik Zayıf Nokta**.
* **3 Boss Skili:** Meteor (%25 Boss Canı), Valkyrie (4 Kalbe Şifa), Dönen Kalkanlar (%50 Defans).
* **Çevre Dinamikleri:** Seviye 5+ Döner Bıçaklar (-0.5 kalp) ve Patlayan Nitro Variller.
* **Gelişmiş Geri Bildirim:** Hit-stop, uçuşan hasar/puan rakamları ve mob eşya dropları.
* **Tam Responsive:** Her telefon, tablet ve masaüstü tarayıcısına otomatik ölçeklenme.

## 🕹️ Kontroller
* **Mobil:** Ekrana dokunup sağa / sola sürükleme.
* **Klavye:** `⬅️` / `➡️` veya `A` / `D` (Hareket), `1`, `2`, `3` (Skiller).

## 🚀 Çalıştırma
```bash
python -m http.server 8080
```
Tarayıcınızda açın: `http://localhost:8080`
